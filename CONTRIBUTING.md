### Developer Certificate of Origin (DCO)

To ensure all code can be legally managed under these licenses, we require all contributors to sign off on their commits using the Developer Certificate of Origin (DCO). 

The DCO is a simple statement asserting that you wrote the code you are submitting or have the legal right to submit it. You agree to this by simply "signing off" your Git commits. 

### How to Sign Off Your Commits

To sign off a commit, add the -s flag when committing from your terminal: 

git commit -s -m "Your descriptive commit message"

This automatically appends a line to your commit message that looks like this:
Signed-off-by: Your Name <your.email@example.com> 

*Note: Your name and email must match your Git configuration and GitHub profile.* 

### Getting Started

1. **Fork the Repository:** Create a fork of the project under your own GitHub account.
2. **Create a Branch:** Create a feature branch off of the main branch (e.g., git checkout -b feature/my-new-feature).
3. **Write Rust/Tauri Code:** Ensure your code is formatted according to project standards (e.g., run cargo fmt and cargo clippy).
4. **Commit with Sign-Off:** Make your changes and commit using git commit -s.
5. **Submit a Pull Request:** Open a Pull Request against our main branch. Describe your changes clearly in the PR description.
